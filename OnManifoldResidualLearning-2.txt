methods feed vec(R) ∈ R9 to the network, which must
learn across the full curved SO(3) manifold. Our residual
replaces this with δθ ∈ R3 , the rotation error, which is
always a small vector near zero. The manifold geometry is
handled analytically by ⊖ before any learning happens.

Expected Advantage
Because δxk is always near zero (the controller is trying
to track the reference), the input domain of the learning
problem is compact and concentrated. A GP prior centred
at zero, or a neural network initialised near zero, is well
matched to this distribution. An ambient-space model
must generalise across all positions, velocities, and orientations the drone might visit. We expect the error-coordinate
model to require fewer training samples to reach the
same residual accuracy.

Hypothesis
For a fixed tracking performance threshold τ (e.g. position RMSE < 0.05 m), the error-coordinate model reaches
τ with fewer training samples than an equivalent model
trained in ambient coordinates. We test this by sweeping
training set size N from 50 to 5 000 samples and plotting closed-loop RMSE for three conditions: nominal (no
residual), ambient-space MLP, and ECRL. The advantage
should grow with trajectory aggressiveness, because larger
attitude excursions make the SO(3) curvature effect more
pronounced.
